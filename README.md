# Battery Barn Toowoomba — static site

A responsive website built with plain HTML, CSS and JavaScript. It has no server-side runtime or third-party form handler. The draft uses the owner-supplied Joomla account backup for the original Battery Barn logo, product photography, business details and page content.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Hosting

This can be hosted from a GitHub repository with GitHub Pages, or on any static hosting provider. The domain `batterybarntoowoomba.com.au` can then point to the published site. Before launch, confirm the domain/DNS access and set up HTTPS at the host.

The included `.htaccess` maps the old Joomla SEF and common non-SEF URLs to the matching sections in the new one-page site. It works on Apache hosting; GitHub Pages does not read `.htaccess`, so use the hosting provider's redirect configuration if publishing there.

## Before launch

- Confirm the contact number, 24-hour roadside availability and current rates.
- Confirm the shop hours shown here (Monday–Friday, 8 am–5 pm; Saturday, 8 am–2 pm) and whether free fitting is still offered as described.
- Review current product and service availability, including WAECO refrigeration work and mobile-phone battery service.
- Set up redirects from existing Joomla URLs to the corresponding sections or page paths to preserve search traffic.

The account archive contains the Joomla site files and database export. Joomla and executable upload files from the old installation are not part of this static site.
